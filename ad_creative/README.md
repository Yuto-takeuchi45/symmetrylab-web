# SymmetryLab Instagram広告準備案

既存HP・LPを変更せず、Instagram広告のクリエイティブ準備だけを行うための別ファイルです。

## 構成

Wiusの公開されている訴求構造を参考に、カルーセル3枚で仮組みしています。

1. 課題提起：戦略コンサルへの転職を、実力で勝ち取る
2. 支援内容：経験を市場価値へ／4つの支援ポイント
3. CTA：キャリアの現在地を整理する／無料相談を予約する

## 現在の状態

- 既存HP・既存LPは変更していません。広告用導線はこのディレクトリに分離しています。
- `/career-check/` は本番接続可能な汎用12ステップUIです。広告ごとの違いはUTMで計測し、必要な場合だけ求人IDを裏側で紐づけます。
- `symmetrylab-career-quiz-lp.html` は広告専用ルートから配信するLP本体です。既存HP・LPからはリンクしません。
- `jobs.json` は任意で求人情報を紐づける場合のデータファイルです。
- Meta側の公開、予算、配信地域、開始日時、第三者提供の確定文面は未完了です。
- `images/hero-consulting.jpg` と既存ロゴを参照しています。既存画像の内容は変更していません。
- WiUsの実広告画像はこのワークスペースにはないため、実物と完全一致させるには参照画像またはリンクが必要です。

## 診断型ファネルのプレビュー

`wius-style-funnel-preview.html` は、静止画ではなく、Wius型の広告導線を確認するための独立UIプレビューです。

- 最初にキャリアの状態を二択で選択
- その後、6問を一問ずつ表示
- 回答ごとに次の設問へ進む
- 前の質問へ戻る／回答状態を保持
- 回答傾向に応じて3タイプの仮結果へ分岐
- 最後に相談導線を表示（遷移先は未設定）

これは既存のHP・LP・求人ページ・計測コードとは接続していません。実際のWius広告と画面単位で一致させるには、Wiusの実広告または操作できるURLが必要です。

## 参照LPに合わせた12ステップ版

共有されたVキャリLPを実際に操作確認したうえで、より近い構造の独立プレビューを追加しました。

symmetrylab-career-quiz-lp.html

- 固定背景＋中央フォームカード
- 冒頭の「近いうちに動きたい／まずは情報収集したい」の二択オーバーレイ
- 12ステップの進捗バーとSTEP表示
- Q1〜Q5・Q8・Q9の単一選択による自動遷移
- Q6・Q7の複数選択＋「次へ」
- Q10の年代プルダウン
- Q11の氏名入力
- Q12のメールアドレス・電話番号入力
- 戻るボタン、離脱防止オーバーレイ、利用規約・個人情報モーダル
- 最終送信は `/api/ad-creative/applications` に接続し、汎用広告導線または公開・受付有効な求人紐づけで受け付けます
- 個人情報同意と提携先への情報提供同意を分けて取得
- 流入情報は非PIIに限定して保存し、Meta `Lead` はDB保存成功後だけ発火

設問は、会社数・相談時期・年収・希望勤務地・最終学歴・希望キャリア・興味のある業界・重視条件・直近の役割・年代の順に整理しています。複数選択の「まだ決めていない」は、具体的な選択肢と同時に選べないようにしています。

参照LPの実データ送信先・利用規約文面・LINE導線はコピーしていません。提携先、第三者提供の利用目的、保存期間、問い合わせ先は公開前に確定版へ差し替えてください。配信前の手順は `META_LAUNCH_CHECKLIST.md` にまとめています。
