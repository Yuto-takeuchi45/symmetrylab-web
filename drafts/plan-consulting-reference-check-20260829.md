# 企画メモ：コンサル転職のリファレンスチェック

## 読者と一つの判断

- 読者：最終選考を通過し、応募先からリファレンスチェックの推薦者提出を求められた在職中の候補者。
- 迷い：現職に転職活動を知られるリスクを抑えつつ、推薦者2名を提出して選考を続けるか、先に代替候補を相談するか。
- 読後の成果物：推薦者2名の関係・共同期間・裏付ける成果3点・連絡方法・現職露見リスクを埋めた「提出判断シート」と、推薦者への依頼文。

## 競合調査（2026-08-29確認）

| 媒体 | URL | 読者に提供している情報 | 自社記事で補う不足 |
|---|---|---|---|
| コンサル転職特化・フォルトナ | https://fortna.co.jp/service/faq/ | ファームによってWebテストやリファレンスチェックがあるという一般的説明 | 推薦者の人数・候補者選定・職務経歴書との照合・依頼文がない |
| コンサル転職支援・ムービン | https://www.movin.co.jp/consulinfo/seminar/seminarKPMG_ST.html | KPMGの公開選考例として面接2回→リファレンスチェック→オファー | 特定選考会の例で、質問項目・現職露見リスク・代替候補の判断がない |
| ハイクラス・JAC Recruitment | https://www.jac-recruitment.jp/market/multi-national-company/foreign-reference-check/ | 外資で通常2名程度、上司＋同僚/部下、方法・英語実施・流れ | 読者が10分で人選を確定する表、依頼文、実績の照合表がない |
| 総合転職・doda | https://doda.jp/guide/careerlibrary/009.html | 目的、方式、質問の例、同意、現職に伝わるリスク | 拒否/代替提出をいつ選ぶか、提出可能な2名を実務実績で判定する手順がない |
| 公的情報・個人情報保護委員会 | https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/ | 同意は本人の意思表示を認識できる合理的な方法が必要 | リファレンスチェックの各企業実務は扱わないため、記事では法的断定を避ける |
| 公的情報・厚生労働省 | https://kouseisaiyou.mhlw.go.jp/consider.html | 公正な採用選考、必要性のない身元調査への注意 | 法律相談ではなく、本人同意・目的・範囲を求人企業へ確認する境界を補う |

## 記事の結論

「推薦者を誰にするか」ではなく、職務経歴書の3つの主張を、立場の異なる2名が具体的な事実で裏付けられるかで提出判断する。現職上司を出せない事情がある場合は、同意前に前職上司・元プロジェクト責任者などの代替案を提示し、企業が許容するかを文面で確認する。
